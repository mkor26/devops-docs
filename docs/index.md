# DevOps Operations Handbook

Учебный сайт документации, собранный из Markdown средствами MkDocs.

**Версия: 2.** Обновление после исправления ссылки.

## Конвейер поставки

1. Изменения предлагаются через Pull Request.
2. Pylint проверяет Python-код.
3. После слияния изменений документации в `main` MkDocs собирает статический сайт.
4. GitHub Pages публикует артефакт сборки.

См. [инструкцию по эксплуатации](runbook.md) и [журнал инцидентов](incidents.md).
