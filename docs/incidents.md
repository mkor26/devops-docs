# Журнал типовых инцидентов

| Инцидент | Симптом | Где смотреть |
| --- | --- | --- |
| Неиспользуемая переменная | Проверка `pylint` завершается с W0612 | Static analysis |
| Недостаточные права | Сборка успешна, публикация завершается ошибкой OIDC | Deploy to GitHub Pages |
| Битая ссылка | Строгая сборка MkDocs завершается с ошибкой | Build documentation или Validate documentation |

При разборе фиксируйте симптом, сообщение журнала, причину, изменение и результат повторной проверки на исправленном коммите.
