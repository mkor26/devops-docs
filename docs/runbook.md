# Эксплуатация

## Публикация

1. Проверьте результат обязательной проверки `pylint` в Pull Request.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation и проверьте задания `build` и `deploy`.
4. Перейдите по URL окружения `github-pages` и проверьте версию на главной странице.

## Ручной запуск

В Actions → Publish documentation выберите Run workflow и ветку `main`.

## Диагностика

Разверните журнал отказавшего шага и сопоставьте сообщение с изменениями в коммите запуска.
