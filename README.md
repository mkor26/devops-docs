# devops-docs

Учебный репозиторий практической работы № 9 по GitHub Actions и GitHub Pages.

- `docs/` — исходные страницы справочника.
- `mkdocs.yml` — конфигурация сайта.
- `.github/workflows/quality.yml` — проверка кода и документации.
- `.github/workflows/pages.yml` — сборка артефакта и публикация сайта.

Каталог `site/` создаётся при сборке и исключён из Git.
